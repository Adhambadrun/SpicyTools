Terminal & Link

				

					Two agent tools, chained: paste a flight into the Terminal to get a
					GDS black-window itinerary, then hand it to Link for booking-ready
					AA / United / Delta / BA / Google Flights / ITA Matrix links and BookWithMatrix JSON.
				

			


			

				

					
SpicyTools Terminal

					

						Paste flights from Google Flights, an airline site, an email or a screenshot. A
						deterministic offline engine returns the GDS black window: real IATA aircraft
						codes, 12-hour clocks, overnight markers, hidden-stop merging, one
						chronological ticket order. Nothing leaves the browser.
					

					
    
						
  • 100% offline — OCR runs in-page; AI is opt-in and never overwrites a good read.
    • 
						
  • Available to agents as POST /api/terminal/convert and the MCP tool gds_itinerary.
    • 
					

					Open the Terminal →
				


				

					
SpicyTools Link

					

						Paste (or inherit) a GDS itinerary and get every booking link an agent needs:
						AA metasearch, AA, United, Delta, British Airways, Alaska, Google Flights and
						ITA Matrix — plus the BookWithMatrix JSON and a fare estimate.
					

					
    
						
  • Open to all — no login required. Just paste your itinerary and go.
    • 
						
  • Arriving from the Terminal? The itinerary is already in the box.
    • 
					

					Open Link →
				

			

		


		

			

				
BCF floating widget

				

					The agent-side companion: a floating search panel for
					bo.bcflights.com. It detects the lead you are looking at and opens
					it in Kayak, Google Flights, ITA Matrix (including mixed-cabin and the ELR/YVR
					trick), PointsYeah or SpicyTools — plus Sabre Fast Search, the VIP itinerary
					maker, the GK converter and the PNR how-to. Every fare on the board above
					offers the same links, built by the same module.
				

			


			

				/bcf-widget.user.js
				
			


			
    
				
  • Install it in Tampermonkey / Violentmonkey, then open any lead on Bo.BCFlights.com.
    • 
				
  • Drag the panel by its header, collapse it to the pepper bubble, hit ⟳ to re-detect.
    • 
				
  • Rebuild it after editing the sources: npm run build --workspace @spicytools/bcf-widget.
    •
